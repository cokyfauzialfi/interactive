Normality & Skewness
▾
🔍 How to Identify
  • Histogram/Density: Long tail, peak shifted
  • Q-Q Plot: Points deviate from diagonal at tails
  • Skewness: |skew| > 1 (substantial), > 2 (severe)
  • Shapiro-Wilk/AD Test: p < 0.05 → non-normality
  • Boxplot: Asymmetric whiskers, one-sided outliers
🔄 Recommended Transformations
Log (ln / log₁₀) Square Root Cube Root Reciprocal Box-Cox Yeo-Johnson
📐 Key Formulas
  • Log: y' = ln(y)
  • Sqrt: y' = √y
  • Box-Cox: yλ = (yλ − 1)/λ (λ≠0); ln(y) (λ=0)
  • Yeo-Johnson: piecewise for y ≥ 0 and y < 0
💡 Interpretation Notes
  • Log coefficients = semi-elasticities (%ΔX → unitΔY)
  • Box-Cox/Yeo-Johnson: always report λ
  • All: back-transform for substantive interpretation
🧪 R Functions
bestNormalize::bestNormalize() car::powerTransform() MASS::boxcox() forecast::BoxCox.lambda() e1071::skewness() nortest::ad.test()
2
Variance Stabilization (Homoscedasticity)
▾
🔍 How to Identify
  • Residuals vs. Fitted Plot: Funnel shape (variance ↑ with fitted)
  • Scale-Location Plot: Trend in √|residuals| vs. fitted
  • Breusch-Pagan/White Test: p < 0.05 → heteroscedasticity
  • Grouped Variance Check: SD scales with mean across categories
  • Plot of SD vs. Mean: Linear relationship → variance ∝ mean
🔄 Recommended Transformations
Log Square Root Arcsine Square Root Freeman-Tukey Anscombe Weighted Least Squares
📐 Key Formulas
  • Log: ln(y) — when variance ∝ mean²
  • Sqrt: √y — when variance ∝ mean (Poisson)
  • Arcsine: sin⁻¹(√p) — for proportions
  • Freeman-Tukey: √y + √(y+1) — low counts
💡 Interpretation Notes
  • Transformations stabilize variance but may not normalize data
  • Check residuals after transformation
  • If variance pattern is complex, consider robust SEs instead
🧪 R Functions
lmtest::bptest() car::spreadLevelPlot() performance::check_heteroscedasticity() bestNormalize::bestNormalize() stats::weighted.mean() # for WLS
3
Linearity & Additivity
▾
🔍 How to Identify
  • Scatterplot + Loess Smooth: Curved pattern (U-shape, diminishing returns)
  • Component+Residual Plot: Non-flat smooth line
  • Added Variable Plot: Curvature after adjusting for covariates
  • RESET/Rainbow Test: p < 0.05 → functional form misspecification
  • Cor(residuals, X²): Significant → quadratic term may help
🔄 Recommended Transformations
Log-Log Log-Level Level-Log Polynomial (X², X³) Fractional Polynomials Splines / GAMs Box-Tidwell
📐 Key Formulas
  • Log-Log: ln(Y) = β₀ + β₁ ln(X) + ε → elasticity
  • Log-Level: ln(Y) = β₀ + β₁X + ε → semi-elasticity
  • Polynomial: Y = β₀ + β₁X + β₂X² + ε
  • Splines: Y = β₀ + f(X) + ε (f = smooth function)
💡 Interpretation Notes
  • Log-Log: β₁ = %ΔY / %ΔX (constant elasticity)
  • Polynomial: interpret via marginal effects or plots, not raw coefficients
  • Splines: report degrees of freedom, knot placement; visualize effect
🧪 R Functions
car::crPlots() car::avPlots() lmtest::reset() mgcv::gam() # for splines mfp::mfp() # fractional polynomials car::boxTidwell() # predictor transforms marginaleffects::plot_slopes() # interpretation
4
Proportions, Rates & Bounded Data
▾
🔍 How to Identify
  • Histogram: Piles up at 0 or 1 (boundary clustering)
  • Variance-Mean Relationship: For proportions, variance ≈ p(1−p)/n
  • Linear Model Predictions: Values < 0 or > 1 (impossible)
  • Residual Q-Q Plot: Skewness when outcome near boundaries
  • Beta Distribution Fit: Data bell-shaped within (0,1) but bounded
🔄 Recommended Transformations
Logit Probit Comp. Log-Log Arcsine Square Root Folded Power Beta Regression Binomial GLM
📐 Key Formulas
  • Logit: ln(p / (1−p)) → maps (0,1) → (−∞, +∞)
  • Probit: Φ⁻¹(p) → assumes normal latent variable
  • Arcsine: sin⁻¹(√p) — variance stabilization
  • Boundary: p* = (p(n−1) + 0.5)/n (Cox adjustment)
💡 Interpretation Notes
  • Logit coefficients = log-odds; exponentiate for odds ratios
  • Beta regression: use predict(type = "response") for original metric
  • Boundary handling: adjust 0/1 values before logit
🧪 R Functions
betareg::betareg() # beta regression car::logit() stats::qlogis() # built-in logit gamlss::gamlss() # zero-inflated beta glm(..., family = binomial) # binomial GLM performance::check_model() # bounded outcome diagnostics

Applied Examples

Real-world illustrations of each issue type, diagnostic finding, transformation applied, and post-transformation interpretation.

Skewness

Scope 3 GHG Emissions (tons CO₂e)

Diagnostic: Skewness = 3.2; Shapiro-Wilk p < 0.001; Q-Q plot shows heavy right tail.

Transformation: Box-Cox, λ̂ = 0.19 (95% CI: 0.14–0.25)

Interpretation: "A 10% increase in Shariah governance score associates with a 2.3-point increase in transformed emissions; back-transformed: ~1.8-ton reduction (95% CI: 0.4–3.2)"

Heteroscedasticity

ESG Disclosure Score by Firm Size

Diagnostic: Breusch-Pagan p = 0.003; residual plot shows funnel shape (variance ↑ with size).

Transformation: Log transformation of disclosure score.

Interpretation: "Coefficients represent % change in disclosure per unit change in predictor; robust SEs used for inference."

Nonlinearity

Shariah Board Independence → Greenwashing Ratio

Diagnostic: RESET test p = 0.008; partial residual plot shows diminishing returns.

Transformation: Log-transform predictor: ln(independence + 1)

Interpretation: "Each doubling of independence associates with β-unit change in greenwashing; effect strongest at low independence levels."

Bounded Proportion

Greenwashing Ratio (misleading claims / total claims)

Diagnostic: 30% of firms at exact 0; linear model predicts −0.02 for small firms.

Transformation: Zero-inflated beta regression (alternative modeling approach — no traditional transform needed).

Interpretation: "Probability of any greenwashing: logit link; conditional mean of ratio: beta distribution with logit link."

Red Flags in Reporting

Common methodological pitfalls when reporting transformed variables — and safer alternatives.

🚩
Reporting raw descriptive stats but transformed regression coefficients without explanation
Creates an interpretive disconnect; suggests carelessness or lack of transparency.
✓ Safer: Report descriptives on raw scale with a clear footnote noting which transformation was used in analysis.
🚩
Using Box-Cox but omitting λ estimate and confidence interval
Prevents replication; obscures which transformation was actually applied to the data.
✓ Safer: Always report: λ̂, estimation method (MLE/grid), 95% CI, and software used (e.g., MASS::boxcox in R).
🚩
Back-transforming without bias adjustment (when means are needed)
Yields the median, not the mean; systematically biased predictions that underestimate the true conditional mean.
✓ Safer: Use marginaleffects::predictions(type = "response") or bestNormalize(..., inverse = TRUE) with bias correction (e.g., Taylor's approximation).
🚩
Transforming only Y but not checking X-linearity
May induce heteroscedasticity or nonlinearity in predictors, undermining the goals of the transformation.
✓ Safer: Check partial residual plots for all covariates after transformation of the outcome variable.
🚩
Arbitrary dichotomization (e.g., median split) after transformation
Causes loss of statistical power, inflated Type I error, and distorted effect sizes — even when intended as a simplification.
✓ Safer: Keep continuous; use splines or polynomial terms if nonlinearity is suspected in the relationship.

01
Rationale
Justifies transformation choice beyond "it looked skewed"
"Due to right-skewness in Scope 3 emissions (skewness = 3.2, Shapiro-Wilk p < 0.001), we applied a Box-Cox transformation to meet OLS assumptions."

Exact Specification
Enables replication; prevents ambiguity about which transform was applied
"We used the natural logarithm (base e); for Box-Cox, λ was estimated by maximum likelihood over [−2.0, 2.0], yielding λ̂ = 0.19 (95% CI: 0.14–0.25)."

Boundary Handling
Critical for log/Box-Cox (requires strictly positive values)
"All emission values were shifted by +0.01 to ensure positivity prior to log-transformation; results were robust to alternative shifts (0.001–0.1)."

Diagnostic Improvement
Shows the transformation actually achieved its intended purpose

✓

Back-Transformation Method
Enables substantive interpretation in the original metric
